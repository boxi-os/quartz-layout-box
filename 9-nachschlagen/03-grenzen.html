Über dieses Handbuch

Dieses Handbuch gehört zum Quartz-Plugin quartz-layout-box. Und es ist mit ihm gebaut: Diese Box hier ist eine Layout-Box.

  • Einstieg — die erste Box in fünf Minuten
  • Platzierung — wo eine Box stehen kann
  • Rezepte — fertige Beispiele zum Abschauen
  • Nachschlagen — alle Optionen auf einer Seite

Sie kommt aus einer Markdown-Datei, nicht aus der Konfiguration — welcher Weg wann der bessere ist, steht in Der Schnipsel.

  • Es filtert nichts
  • Es kennt keine Bedingungen
  • Es rendert keine Obsidian-Syntax
  • Es merkt sich nichts im Browser
  • Der Zwischenspeicher hängt an der Änderungszeit
  • Schnipsel sind öffentlich
  • Was bewusst fehlt

9.3 – Grenzen

9.3 – Grenzen

10. Sept. 20262 Min. Lesezeit

Es filtert nichts

Ein Schnipsel wird eingesetzt, wie es dasteht — als HTML, ungeprüft. Das ist der Zweck: Wer ein <svg> oder ein <style> einsetzen will, soll es können.

Die Folge: Nur Dateien verwenden, die man selbst kontrolliert. Ein Schnipsel aus fremder Quelle ist so vertrauenswürdig wie fremdes JavaScript. Für Werte aus der Seite gilt das nicht — Platzhalter werden maskiert (4.1).

Es kennt keine Bedingungen

Keine Ausdrücke, keine Vergleiche, keine Regeln je Ordner. Eine Seite kann eine Box ausblenden oder ihr Schnipsel tauschen, mehr nicht. Warum, und was stattdessen hilft: 6.2.

Es rendert keine Obsidian-Syntax

Wikilinks, Callouts, Einbettungen bleiben in einem Markdown-Schnipsel stehen, wie sie geschrieben sind. Das Plugin ist eine reine Komponente und sitzt hinter der Inhaltspipeline (1.3).

Es merkt sich nichts im Browser

Eine aufgeklappte Box ist nach dem nächsten Seitenwechsel wieder so, wie collapsed es sagt. Ohne JavaScript geht es nicht anders — und ohne JavaScript ist eine Entscheidung, keine Lücke (5.1).

Der Zwischenspeicher hängt an der Änderungszeit

Nicht am Inhalt. Wer eine Datei mit dem alten Zeitstempel zurückschreibt, sieht die alte Fassung. Betrifft im Alltag nur das Zurückspielen aus einem Archiv.

Schnipsel sind öffentlich

Sie liegen unter quartz/static/ und werden mit ausgeliefert. Über die Adresse der Site sind sie abrufbar. Für Markup, das ohnehin auf jeder Seite steht, ist das folgenlos — als Ablage für etwas Nichtöffentliches taugt der Ordner nicht.

Was bewusst fehlt

  • Kein Zeitplan. Keine Box, die am Montag erscheint und am Freitag verschwindet.
  • Keine Vorlagensprache. Platzhalter setzen Werte ein; sie können nicht rechnen, verzweigen oder wiederholen.
  • Keine eingebaute Gestaltung. Bis auf zwei Regeln für Bilder bringt das Plugin kein Aussehen mit (5.2).
